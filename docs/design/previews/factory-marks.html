The Countersigned F

An F built as ledger records on a spine — a full top bar and a shorter middle bar bound to a vertical spine — with a detached square, the countersign slot, floating beside the middle bar, right-aligned to the top bar's edge. It reads F first, ledger second. Family grammar: like Forge's tally square and Watchtower's health bay, the mark miniaturizes the product's core semantic, and exactly one element may carry color.

02 · The chip is live — favicon states
CLEAR · sig-ok
ATTENTION · sig-warn
DISCONNECTED · ink-faint
STATIC · accent

Live favicon: amber when the attention projection has items, green when clear, faint when disconnected. Static contexts (README, app icon, login, exports) always use accent lavender. Ship one favicon file per state and swap the <link>; never recolor via canvas. The aria-label is the text twin. Only the chip ever takes color — a second colored element would read as a meter.

03 · Lockup
FACTORY

IBM Plex Sans 700 · .18em · uppercase · mark at left, 10px gap, optically centered on cap height. Never recolor a letter — the chip carries all the color. Never put the mark in a circle or badge. Below 16px use the mark alone.

05 · Rules
  • Do — draw bars in currentColor so one asset serves chrome, docs, and print.
  • Do — keep the chip's meaning narrow: attention state only, with a text twin.
  • Don't — add gears, smokestacks, conveyors, or a third bar. The F is records on a spine, nothing more.
  • Do — use the dimensional rendition (stamped metal, lit LED) at ≥32px; flat currentColor below that. The chip is the only element that emits light; the F reflects it.
  • Don't — color more than the chip, glow anything but the chip, glow at favicon sizes (it turns to mud), or escalate severity by coloring bars.
  • Don't — set the wordmark without the mark above 16px, or box the mark in a circle/badge.

Greyscale: the chip flattens; acceptable only because the favicon is ambient — the Attention lane in the app is the authoritative surface.
